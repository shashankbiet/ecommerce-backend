# Release checklist

## Pre-release

- [ ] Scope is complete and aligned with issue/PR
- [ ] Tests/lint/build checks passed
- [ ] Contract/data changes documented
- [ ] Rollback strategy confirmed
- [ ] Observability checks identified

## Release

- [ ] Deploy in approved order
- [ ] Run smoke checks
- [ ] Verify critical user journeys

## Post-release

- [ ] Monitor errors/latency for regression
- [ ] Confirm no critical alert spikes
- [ ] Capture follow-up actions
